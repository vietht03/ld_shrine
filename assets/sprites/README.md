# Sprite Sheet Info

Ảnh sprite sheet kẻ địch (`enemy_sheet.png`) được cut theo grid 3×2:

| Col 0 | Col 1 | Col 2 |
|-------|-------|-------|
| Row 0: Peasant | Thief | Footman |
| Row 1: Armored Knight | Shadow Mage | Boss |

Mỗi ô: 341×512 px (từ ảnh 1024×1024)

## Dragon Sprites
- `fire_dragon.png` → FireDragon tower
- `ice_dragon.png` → IceDragon tower  
- `poison_dragon.png` → PoisonDragon tower
